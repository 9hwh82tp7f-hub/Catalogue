Publication directe sur GitHub Pages

Renseigne une fois ces informations : à chaque clic sur « Publier en ligne », le fichier sera envoyé directement dans ton dépôt GitHub et le site sera mis à jour automatiquement après la publication GitHub Pages. Le dépôt, la branche et le chemin sont conservés localement. Le jeton n'est jamais conservé dans localStorage : il reste uniquement en mémoire de session et doit être ressaisi après fermeture du navigateur.

🔒 Ce panneau est dédié à cette seule mini application (catalogue Telegram) — il n'accepte que des fichiers générés par elle.
